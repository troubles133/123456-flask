# Лабораторная работа: Flask + MySQL

## Описание
Веб-приложение на Flask с реализацией регистрации и авторизации пользователей. Пароли хранятся в базе данных в виде хешей (с использованием `werkzeug.security`).

## Технологии
- Python 3.8+
- Flask
- MySQL (mysql-connector-python)
- Werkzeug (для хеширования паролей)
- uv (менеджер пакетов)
